# Bonk Slop

A gorilla-arm brawler for Meta Quest: swing around on your arms, mine the cave behind the cabin, dodge the cave monster, and bonk your friends in rooms of up to 5 players.

**Download and install:** https://dummonk1403.github.io/bonk-slop/ (open it in the Meta Quest Browser on your headset)

Direct APK link (v1.5): https://github.com/Dummonk1403/bonk-slop/releases/download/v1.5/BonkSlop.apk

- **The download link installs the game.** Installing games from outside the Meta Horizon Store needs Developer Mode on your headset (switched on from the Meta Horizon phone app).
- **A room code joins your friends.** In the game, type a code on the lobby computer in the cabin: one person presses CREATE, everyone else types the same code and presses JOIN.

Already have Bonk Slop? Install the new APK over it and choose Update. Don't uninstall first: your progress is saved on the headset.

This repository only holds the download page and the release files.
